## Featured projects

### [Firefox Backup Manager](https://github.com/lebvmikhail/firefox-backup-manager)

A Windows utility for backing up Mozilla Firefox profiles to 7-Zip archives, checking archive integrity, and restoring a profile into a separate folder.

- **Stable release:** [v1.0.0](https://github.com/lebvmikhail/firefox-backup-manager/releases/tag/v1.0.0)
- **Latest preview:** [v1.0.1-beta.1](https://github.com/lebvmikhail/firefox-backup-manager/releases/tag/v1.0.1-beta.1)
- **Stack:** C#, Windows, 7-Zip, PowerShell, GitHub Actions
- **License:** GPL-3.0

The project emphasizes careful handling of backup data, archive verification, safe recovery, and honest documentation of limitations.

### [Cudy WR3000U LED Schedule](https://github.com/lebvmikhail/cudy-wr3000u-led-schedule)

A practical, bilingual guide for scheduled LED shutdown and morning restoration on the Cudy WR3000U router running OpenWrt. It documents a seven-LED LuCI configuration, a cron-based night-time safeguard, and verification and rollback steps.

- **Release:** [v1.0.0](https://github.com/lebvmikhail/cudy-wr3000u-led-schedule/releases/tag/v1.0.0)
- **Tested configuration:** Cudy WR3000U (256 MB), OpenWrt 25.12.5, build r33051, LuCI branch 26.180.75667
- **Documentation:** Russian and English
- **Documentation license:** CC BY 4.0

The guide acknowledges the 4PDA groundwork by zerocash, skafin, and moderator a43. Third-party materials remain subject to their own rights and terms.
