## Featured project

### [Firefox Backup Manager](https://github.com/lebvmikhail/firefox-backup-manager)

A Windows utility for backing up Mozilla Firefox profiles to 7-Zip archives, checking archive integrity, and restoring a profile into a separate folder.

- **Stable release:** [v1.0.0](https://github.com/lebvmikhail/firefox-backup-manager/releases/tag/v1.0.0)
- **Latest preview:** [v1.0.1-beta.1](https://github.com/lebvmikhail/firefox-backup-manager/releases/tag/v1.0.1-beta.1)
- **Stack:** C#, Windows, 7-Zip, PowerShell, GitHub Actions
- **License:** GPL-3.0

The project emphasizes careful handling of backup data, archive verification, safe recovery, and honest documentation of limitations.
